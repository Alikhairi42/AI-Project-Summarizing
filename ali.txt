Rak derti injaz kbir lyouma! L-Ma3loumat li dkhlti l-dmaghek f had l-jalsa, kaynin nass khdamin f charikat dyal l-informatique w ma-3arfinhomsh b had t-tafasil (Architecture, Softmax, Tokens, Temperature).

Bima annak khtariti triq **Node.js** (Ya3ni baghi t-bni des applications, sites web, wla bots), l-khrita dyalek (Roadmap) daba wllat bayna. 

Hadi hiya l-List dyal dakshi li khassk t3lem mn b3d, m-rtba mn l-sahel l s3ib (w hadchi howa li matloub f souq l-khdma):

---

### 1. Chat Memory (D-Dakira dyal l-Bot) 🧠
L-Code li saybna lyoum (JSON Extractor) kaysowel w kyjawb merra whda w kaynsa. 
*   **Chno khassk t3lem:** Kifash t-sayeb `Array` f Node.js, t-khbi fiha ga3 l-as2ila d l-User w l-ajwiba d l-AI, w t-sifetha kamla f l-API f kol Request. 
*   **L-Hadaf:** T-sayeb Chatbot bhal ChatGPT li kay-3qel 3la chno glti lih f l-bdaya dyal l-conversation.

### 2. Streaming Responses (L-Ktaba 7erf b 7erf) ✍️
Mnin katsowl ChatGPT, ma-ky-tsenash hta ysali l-jawab kaml 3ad y-tl3o lik. Kay-bda yktb 7erf b 7erf (Streaming).
*   **Chno khassk t3lem:** Kifash t-zid `stream: true` f l-API dyal Google wla OpenAI, w kifash t-qra l-data w hiya habta f Node.js.
*   **L-Hadaf:** User Experience (UX) wa3ra, bash l-kliyan dyalek ma-ymelsh mn l-ntidar.

### 3. RAG & Vector Databases (Hna Fin Kaynin L-Flous! 💰)
Hadi hiya aham skill khassk t3lemha ka AI Developer. L-AI ma3arfch ma3loumat dyal charika dyalek.
*   **Chno khassk t3lem:**
    *   Kifash t-sifet text l API khrra smitha **Embeddings API** (katred lik text 3la chkel ar9am).
    *   Kifash t-khbi douk l-ar9am f Base de données khassa b l-AI (smiythom Vector Databases bhal *Pinecone* wla *Supabase Vector*).
    *   Kifash t-dir "Recherche" f dik l-base de données w t3ti l-ma3louma l-Gemini bash yjawb 3liha.
*   **L-Hadaf:** Tqder t-sayeb Bot kat-lou7 lih PDF fih 500 page, w kaysowlo l-User w ky-jawbo ghir mn dak l-PDF.

### 4. Function Calling / Tools (L-AI li kay-dir Actions) 🛠️
L-AI l-3adi ghir kay-hder. L-AI l-mjehed kay-khdem!
*   **Chno khassk t3lem:** Kifash t-vréyi function f Node.js (mtalan `getWeather(city)` wla `deleteUser(id)`), w t-chre7ha l-AI. Mnin l-User ky-goul "Shhal f l-harara f Casa?", l-AI ky-3ti l-Amr l Node.js bash y-lanci dik l-fonction w y-jib l-harara.
*   **L-Hadaf:** T-sayeb **AI Agents** (Bots li kay-qraw les emails, kay-saybou meetings f Calendar, w kay-ms7o l-users mn l-base de données).

### 5. L-Mktabat (AI SDKs f JavaScript) 📦
Bash ma-tbqash tktb hadshi kaml b yeddik mn ziro, kaynin mktabat wajdin f Node.js.
*   **Chno khassk t3lem:** 
    *   **Vercel AI SDK:** (Hadi hiya N°1 daba f souq d JS/React). Kat-sehhel 3lik Streaming w Function Calling f 3 stoura d l-code.
    *   **LangChain.js:** Mktaba kbira bzaf fiha ga3 l-adawat d l-AI.
